## Value

- Centrality: Core
- For: engine developers who must keep an exactness-critical companion to a quantized plane
- Problem: several planes are already quantized while keeping a full-precision companion (KV pre-RoPE K, V4.1 hot rows, a planned FP4-with-f32-Kraw), but the pattern is emergent and unnamed, so its invariant ("the shadow is bit-exact") is untested as a contract
- Today: each site hand-rolls an f32 reservation and relies on a comment to say why
- Better because: one named contract says "plane X is quantized with an exact shadow at level Z for purpose W", and a round-trip test enforces the bit-identity
- P1: advanced - generalizes the shipped "pre-RoPE K stays f32 while attended K/V are q8_0" trick into a reusable contract
- P2: advanced - makes mixed storage that MUST stay mixed expressible and testable instead of emergent
- P3: advanced - additive; the existing KV "mixed" label and V4.1 hot-row override become the first two instantiations, unchanged
- P4: advanced - gives operators one word and one receipt for "this plane carries an exact shadow"

## Current state

`internal/compute/kvprecision.go:87` `perTokenPerLayerBytes` keeps the pre-RoPE K
row **f32** while the attended K/V are q8_0; the storage label is literally
`"mixed"` (`:60`) and the header explains the reason is **exact eviction**. V4.1
hot rows ship an exact FP8+E8M0 override on top of quantized shards. A blackwell
plan decides "tier precision per plane; FP4 weights/V/read-K with an f32 `Kraw`
shadow". `internal/quantmeta/contract.go:171` `KVSpec` already models K and V
independently with a full-precision sink/recent window (`:174-175`), but no type
or interface names the shadow or asserts its bit-identity.

## Core through-line

Add `internal/compute/shadow.go` with:

```go
// ShadowPurpose names why a plane needs an exact companion.
type ShadowPurpose string // "exact-eviction" | "hot-row-override" | "quality-floor"

// ShadowLifetime names how long the shadow is retained.
type ShadowLifetime string // "resident" | "per-token" | "on-evict"

// Shadow declares an exactness-critical companion to a quantized plane.
type Shadow struct {
    Purpose  ShadowPurpose
    Dtype    Dtype          // the shadow's dtype; must be strictly wider than the plane
    Lifetime ShadowLifetime
}

// Shadowed pairs a quantized Tensor with its exact shadow Tensor.
type Shadowed struct {
    Quant  Tensor
    Shadow Tensor
    Spec   Shadow
}
```

A constructor that fail-closes when `Shadow.Dtype` is not strictly wider than the
quantized plane's dtype (by the registry's rank from child 01), and a check that
the shadow is **bit-identical to the pre-quantization source** for the covered
elements. The KV `mixed` reserve and the V4.1 hot-row override become the first
two named instantiations, proving the contract by construction.
