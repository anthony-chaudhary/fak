# Scratch arm

Use the pinned `fak` binary in an otherwise empty arm directory. Do not inspect the other arm, repository examples, product manifests, locks, or generated answer files.

You receive only the behavioral requirements in the byte-identical `../../task-card.md`. Construct the equivalent harness product from scratch and complete every stated outcome. You may use `fak harness --help`; the task does not prescribe which harness commands you use.

Ask the facilitator for a hint only when you would otherwise stop; every hint is recorded as one help request. Keep every command and output in your arm directory. Stop the clock only at the boundary stated in the task card.
