## Algorithm notes (honest substitutions)

- **LFRU** (tinyserve): victim minimizes `freq / age`, `age = clock - lastUse + 1`; `freq`
  counts lifetime accesses (resident or evicted). Compared as an exact cross-multiplied
  rational, not a lossy float.
- **Score-EMA** (HybriMoE): on each access the touched group gains `alpha * s_routed` and
  every other score decays by `(1-alpha)`, `alpha = 0.5`. **HybriMoE drives `s_routed` from
  `torch.topk` routing probabilities (`experts.py:677-690`); the offline stream carries no
  routing score, so an access indicator (`1.0`) stands in.** The substitution is documented
  in code and owned here rather than hidden. `alpha = 0.5` keeps scores dyadic, so equality
  ties are real, not float noise.
- **Belady bound:** `replayoracle.Belady` — exact bitset DP at ≤63 distinct groups
  (`OPTExact=true`), farthest-next-use greedy above that (`OPTExact=false`). LFRU/ScoreEMA
  are demand-paging arms, so the demand-paging Belady bound applies; no arm exceeded it.

## Result: the simulated delta at fixed ring bytes

At every one of the eight matched capacities the ordering is stable:

- **LFRU > LRU** (strictly at 7 of 8 capacities; at cap 4 the LRU baseline rounds to
  0.000 while LFRU is 0.005): `0.005 vs 0.000` @ 0.066 GiB through `0.400 vs 0.293` @
  8.438 GiB. **Simulated absolute delta = +0.005 to +0.107 hit-rate points.** The relative
  ratio ranges from 1.37× (cap 512) to 3.25× (cap 8); it is not a constant ~2×.
- **Score-EMA is provably hit-equivalent to LRU** on any stream carrying only an access
  indicator, at `alpha = 0.5`. The uniform `(1-alpha)` decay is a positive affine scaling
  that preserves the argmin, and the touched group receives the same `alpha` regardless of
  its prior value, so the victim comparison reduces exactly to recency — i.e. LRU. This was
  checked exhaustively over 696,320 small streams (alphabet {0,1,2,3}, lengths 6–9,
  capacities {2,3}) with **zero** hit-rate differences, and `TestCacheTraceScoredArmsAreLive`
  now asserts the equivalence rather than hunting an impossible witness. `TestScoreEMAVictim
  SelectionIsLive` separately proves the code path reads the score map (white-box
  contradiction case), so the arm is live even though its hit count collapses to LRU's.
  **Consequence: the access-indicator substitution erases the score signal, and the true
  score-EMA behavior on a real routing trace cannot be inferred from this sim.**
- **LFRU does not beat LFU**: `0.005 vs 0.008` @ 0.066 GiB, `0.400 vs 0.439` @ 8.438 GiB.
  Frequency-only retention wins on a stationary Zipf stream, which is the expected result —
  a skewed stationary distribution rewards pure frequency.
- **All arms ≤ OPT** at every capacity (Belady bound holds). OPT is 0.044–0.546.

The fixed-ring-byte delta for the ported score-aware arms over the shipped LRU baseline is
real for LFRU (+0.005…+0.107 absolute, 1.37×…3.25×) and **provably zero for score-EMA with
an access indicator**. That is the offline evidence the ticket asked for, recorded before
any engine policy change.

**Honest limit:** this is a synthetic i.i.d. Zipf stream, not a captured strix3 trace. The
score-EMA substitution (access indicator for the routed probability) is exactly the part
that a real trace would carry, and the equivalence proof above shows the substitution
collapses the arm to LRU. A real routing-score stream is therefore required before any
score-EMA claim can be made; no production envelope claim is made here.
