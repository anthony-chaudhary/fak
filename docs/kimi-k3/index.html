Send K3-native controls

macOS / Linux
export MOONSHOT_API_KEY="your-key"
./scripts/claude-kimi-k3.sh
PowerShell
$env:MOONSHOT_API_KEY = "your-key"
.\scripts\claude-kimi-k3.ps1
Your credential stays in the environment. The launcher resolves it by name; it does not write the secret into the repository.
