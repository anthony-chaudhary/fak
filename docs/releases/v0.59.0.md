# fak v0.59.0: Minor release for inkling2, metal, ci, ggufload

This release contains 50 commits: 6 what changed changes, 16 reliability and correctness changes, 25 engineering quality and evidence changes. The sections below are grouped by operator impact, with the complete source history retained for auditability.

## What changed

### Security & Governance
- Floor effort and irreversible loop depth at the trained pass count, adding the TrainedLoops capability (fak-private inkling-effort-trained-loops-r2-20261126).

### Serving Engine, Gateway & Kernel Acceleration
- Bind the Inkling-2 prefix store to its loop depth.
- Inkling-2 cohorts restore rows from a bounded cross-request prefix store (opt-in FAK_INKLING2_BATCH_PREFIX_CACHE_MIB) so a next turn or a shared system prompt skips re-prefill; RTX 5080 4-row multi-turn trace prefills 24168 -> 4201 prompt tokens, TTFT p50 1.36 s -> 0.155 s, greedy tokens within the scalar near-tie bound.
- Reuse Inkling-2 Metal prefill chunks across serve requests.
- Speculate by default on the resident Metal target of fak run with the auto draft (DFlash2 width chooser when present, else lookup), stop greedy decode at EOS, warm verify widths lazily, no Metal graph capture.

### Developer Platform, Tooling & Evidence
- Land stranded L3 bind-safety admission, snapshot ConfineDir, Kimi K3.1 KDA chunked prefill and upstream-gaps note (not yet wired).

## Engineering quality and evidence

### Security & Governance
- Clear demo-debt in serve-receipt, piidemo and agent-ab so the zero-debt gate passes.
- Guard that a restored prefix-reuse append decodes bit-equal to a split-matched fresh prefill.

### Autonomous Agent & Multi-Model Harness
- Inkling2 resident now wires mapped GGUF weights at model open and session plus DFlash2 draft buffers at session open by default, so a short prompt's first prefill no longer waits on residency.

### Serving Engine, Gateway & Kernel Acceleration
- Batched-only mode and a bounded lease wait for the inkling2 Metal prefill hardware test.
- Fix preflight, install and model claims; add CLI reference.
- Grouped GEMM bench defaults to Inkling-2-Mini's 128 experts, FAK_INK2P_BENCH_EXPERTS overrides.
- Keep the inkling2 DFlash2 draft mapped and its Metal weight views wired across requests in a refcounted process cache keyed by draft dir and file identity.
- Latency-tuned dense decode GEMVs, exact bf16 controller weights, shaped routed iq kernels, fixed-step qkv_post/attend and a pipelined resident decode step for Metal inkling2, all bit-identical; Inkling-2-Mini Q3_K_XL resident plain decode on M3 Pro 25.9 -> 29.0 tok/s over wave 1 (GPU 36.6 -> 34.2 ms/token, wall ~= GPU with the step pipelined), device greedy ids equal the host, pipelined ids equal plain, off switches FAK_INK2_LEGACY=mvlat|ctrlmix|routed2|tinyfuse|pipeline.
- Metal Inkling-2 prefill binds a 2048-token chunk by default, admitted against the Metal working set and halved toward 512 when it does not fit (fak-private inkling2-metal-prefill-w2-chunk-20261126).
- One-command CUDA run path with the exact fak run line (fak-private inkling-stranger-cuda-run-path-r2-20261126).
- Position the resident serve prefix-slot knobs, the batch prefix store, the resident ctx bound and the inkling2 serve loader so the lane adds no coverage debt.
- Run Metal inkling2 decode on a concurrent encoder with reflection-derived hazard barriers, fold the per-expert scale into the routed GEMV store with register NVFP4 decode, and replace the decode mix/rms/route/control kernels with lean named-load kernels, all bit-identical; Inkling-2-Mini Q3_K_XL resident plain decode on M3 Pro 25.3 -> 27.7 tok/s interleaved (GPU 37.7 -> 34.5 ms/token), device greedy ids equal the host forward, off switches FAK_INK2_LEGACY=serial|routed|scale|nvfp4w|mix|ctrl|rms|route, FAK_INK2_PROFILE=stats decode-window report.
- Run the inkling2 DFlash2 draft linears in int8 by default and key the int8 cache by weight content so requests reuse one quantized copy.
- Scope CUDA contract witnesses back to their production files.
- Seed the inkling2 DFlash2 width chooser with a measured per-width verify table, the bent MMA curve kept as measured and the draft in the same width-1 unit.
- Split internal/model into three test-name buckets so it stays under the 20m per-binary bound.
- Split qwen35 prefill metal sequence out of q4k godfile.
- The docs index names the retitled page as fak's native Inkling Metal path and links the vendored-runtime retirement record, instead of listing it as a vendored runtime.
- Width-invariant simdgroup_matrix verify kernels for inkling2 behind FAK_INKLING2_VERIFY_MMA=1, plain spec steps as width-1 MMA verifies, and drop a duplicate envconfiglint admission.
