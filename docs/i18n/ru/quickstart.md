# fak — быстрый старт: 10 минут до локальной модели

> Это **локализованная точка входа**, а не полный перевод документации.
> Полная документация — на английском; эта страница даёт суть fak, 60-секундное

> [английскому первоисточнику](https://github.com/anthony-chaudhary/fak/blob/main/README.md).

## Обещание

От нуля до **управляемого локального ИИ примерно за 10 минут**: работает офлайн, не требует
API-ключа, не создаёт облачного счёта, данные не покидают вашу машину, а для небольших
моделей достаточно CPU — GPU не нужен.

## Самый быстрый путь

Оберните ваш уже существующий агент одной командой:

```bash
fak manage claude
```

Вы не переписываете агент. Либо перенаправляете один base URL на `fak serve`, либо
оборачиваете агент в одну команду `fak manage claude` — и каждый tool call сначала
проходит через capability floor.

## 60-секундное доказательство (без ключа, без модели, без GPU)

```bash
go build -o fak ./cmd/fak
./fak preflight --policy examples/customer-support-readonly-policy.json --tool refund_payment --args "{}"   # -> DENY (POLICY_BLOCK)
./fak preflight --policy examples/customer-support-readonly-policy.json --tool search_kb     --args "{}"   # -> ALLOW
./fak agent --offline                                                                                       # injection blocked, task still completes
```

Первый вызов отклоняется структурно (`DENY`), второй разрешается (`ALLOW`), а `fak agent
--offline` доводит задачу до конца, отбив prompt injection. В живых тестах инъекция
пробивала незащищённый базовый агент 5 из 5 раз; fak отсекал её 5 из 5.

## Что такое fak

**fak — это одна статическая Go-бинарь**, которая стоит между вашим ИИ-агентом и
инструментами, которые он вызывает. Она проверяет каждый tool call *до* его запуска и
переиспользует повторяющуюся общую работу в длинной сессии. Итог: тот же цикл агента
становится **безопаснее, дешевле и быстрее** — без переписывания.

- **Default-deny по структуре.** Capability floor проверяется *внутри* ядра, на том же
  пути вызова, и **fail-closed**: действие, которого нет в allow-list, не выполнится,
  что бы модели ни внушили. Это не классификатор, который надо «обучать ловить атаки».
- **Карантин результатов.** Подозрительные *результаты* tool call удерживаются вне
  контекста модели целиком — это структура, а не детектор. Детектор, помечающий их,
  считается по замыслу почти на 100% обходимым — он бонус, а не опора.

## Насколько это быстро (честная граница)

На измеренной сессии **50 ходов × 5 агентов** честный выигрыш — примерно **4.1× меньше
работы**, чем у *настроенного* стека с тёплым кэшем (tuned warm-cache).

Цифра **~60×** (около 19 часов против примерно 19 минут) верна **только против наивного
цикла**, который каждый ход пересылает всё заново; подавать её как заголовочную нельзя.
Выигрыш от переиспользования доступен **только при self-host** и применим к
read-heavy-флотам.

Скидка provider prompt-cache сохраняется лишь пока кэшированный префикс байт-в-байт тот
же. fak **гарантирует байтовую идентичность префикса**, отбрасывая старые средние ходы;
переиспользует ли провайдер кэш на самом деле — решение провайдера, которое fak
транслирует, а не выдаёт за своё.

**Про маржу в рублях.** Токены оплачиваются провайдеру, а счёт вам приходит в рублях —
поэтому меньше работы на ту же сессию напрямую снижает затраты и поднимает маржу. При
self-host весь путь бесплатен: **Apache-2.0**, без карты, без трансграничного инвойса, без
юрлица.

**Данные остаются на вашей машине (152-ФЗ).** fak — self-host-first: статическая бинарь
стоит перед **локальной моделью** или отечественным provider, данные не уходят за пределы
периметра, а каждый tool call фиксируется в защищённом от подделки audit log. Это упрощает
локализацию персональных данных по требованиям **Федерального закона № 152-ФЗ**.

## Ваша модель

fak не заменяет вашу модель — он ею управляет и кэширует её. **Qwen2/Qwen3 и GLM-MoE**
подтверждены как bit-exact во встроенном (in-kernel) референс-движке. Всё остальное
(DeepSeek, Mistral, любая open-weights модель) подключается по OpenAI-совместимому
протоколу: Ollama / vLLM / SGLang / llama.cpp / LM Studio или любой OpenAI-совместимый API.

## Установка

```bash
git clone https://github.com/anthony-chaudhary/fak.git && cd fak
go install github.com/anthony-chaudhary/fak/cmd/fak@latest
```

**Про GOPROXY.** Если `proxy.golang.org` недоступен, задайте `GOPROXY` перед установкой —
подойдёт и самостоятельно развёрнутый Go module proxy:

```bash
export GOPROXY=https://<your-go-module-proxy>,direct
go install github.com/anthony-chaudhary/fak/cmd/fak@latest
```
