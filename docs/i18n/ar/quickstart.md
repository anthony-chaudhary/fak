# fak — البداية السريعة: ذكاء اصطناعي محلي محكوم في نحو ١٠ دقائق

> هذه **صفحة دخول مُوطّنة (entry point)**، وليست ترجمة كاملة للتوثيق. التوثيق الكامل
> بالإنجليزية — تمنحك هذه الصفحة جوهر fak، وإثبات الستين ثانية، ومسار التشغيل، ثم تُحيلك
> إلى [مصدر الحقيقة الإنجليزي](https://github.com/anthony-chaudhary/fak/blob/main/README.md).
> **تنبيه:** هذه الصفحة مُولّدة آليًا وبانتظار مراجعة متحدّث أصلي — لأي تصحيح افتح
> issue أو PR.
> **لغات أخرى ومداخل أخرى:** [مركز i18n](../README.md).

## الوعد

من الصفر إلى ذكاء اصطناعي محلي **محكوم** في نحو ١٠ دقائق: يعمل دون اتصال (offline)، دون
مفتاح API، دون أي فاتورة سحابية، وبياناتك تبقى على جهازك. المعالج (CPU) وحده يكفي للنماذج
الصغيرة — لا حاجة إلى GPU.

## المسار الأسرع (أمر واحد)

غلّف وكيلك الحالي بنموذج محلي في أمر واحد — دون مفتاح، دون شبكة:

```bash
fak manage --gguf qwen2.5:7b -- claude
```

لا تُعيد كتابة وكيلك. إمّا توجّه base URL واحدًا إلى `fak serve`، أو تلفّ الوكيل القائم
بالأمر أعلاه، فتمرّ كل tool call عبر أرضية الصلاحيات (capability floor) *قبل* أن تُنفَّذ.

## إثبات في ٦٠ ثانية (دون مفتاح، دون نموذج، دون GPU)

```bash
go build -o fak ./cmd/fak
./fak preflight --policy examples/customer-support-readonly-policy.json --tool refund_payment --args "{}"   # -> DENY (POLICY_BLOCK)
./fak preflight --policy examples/customer-support-readonly-policy.json --tool search_kb     --args "{}"   # -> ALLOW
./fak agent --offline                                                                                       # injection مُوقَف، والمهمة تكتمل رغم ذلك
```

الحدّ الافتراضي هو **الرفض (default-deny)**، ويُفحَص *داخل* النواة على مسار الاستدعاء
نفسه: فعلٌ ليس على قائمة السماح لا يمكن أن يُنفَّذ مهما جرى إقناع النموذج به — فشلٌ آمن
(fail-closed)، لا انفتاح. وفي اختبارات حيّة، اخترق حقنُ الأوامر (prompt injection) خطَّ
الأساس غير المحمي ٥ من ٥، بينما جدَره fak ٥ من ٥.

## ما هو fak؟

**fak** ملفٌّ Go ثنائي واحد (static binary) يجلس بين وكيل الذكاء الاصطناعي والأدوات التي
يستدعيها. يراجع كل tool call قبل تشغيله، ويعيد استخدام العمل المشترك المتكرر عبر الجلسة
الطويلة — فتصبح **نفس** حلقة الوكيل أكثر أمانًا وأرخص وأسرع، دون إعادة كتابة.

- **حجرٌ صحّي للنتائج (quarantine).** النتائج المشبوهة تُحجَب عن سياق النموذج بالكامل —
  بِنيةً لا بمُصنِّف؛ فالكاشف الذي يُعلّمها يُعامَل بوصفه قابلًا للتحايل ~١٠٠٪، مكافأةً لا
  أرضية.
- **يبقى نموذجك نموذجك.** fak يحكم نموذجك ويخزّنه مؤقتًا، ولا يستبدله. **Qwen2/Qwen3**
  و **GLM-MoE** مُثبَتة bit-exact في محرّك النواة المرجعي؛ وكل ما عداها (DeepSeek،
  Mistral، أي نموذج مفتوح الأوزان) يتّصل عبر الواجهة المتوافقة مع OpenAI — عبر Ollama /
  vLLM / SGLang / llama.cpp / LM Studio أو أي OpenAI-compatible API.

## كم هو أسرع؟ (بأمانة)

على جلسة مقيسة بـ ٥٠ دورة × ٥ وكلاء، الرقم الأمين هو **~4.1× عملٌ أقل** مقابل مكدّس
warm-cache **مضبوط (tuned)**. أمّا رقم **~60×** (نحو ١٩ ساعة إلى نحو ١٩ دقيقة) فصحيحٌ
**فقط مقابل النمط الساذج** الذي يعيد إرسال كل شيء كل دورة — لا تقدّمه أبدًا كعنوان رئيسي؛
العنوان الأمين هو 4.1×. مكسب إعادة الاستخدام **للاستضافة الذاتية فقط (self-host)** وينطبق
على الأساطيل كثيفة القراءة.

خصم التخزين المؤقت للمزوّد (prompt-cache) لا يصمد إلا إذا بقيت البادئة المخزّنة متطابقة
بايتًا ببايت؛ يُسقط fak الأدوار الوسطى القديمة مع إبقاء البادئة **متطابقة بايتيًا** —
وهذا ما يضمنه fak. أمّا استعمال المزوّد لذلك التخزين فقرارُه هو، وينقله fak دون أن
يدّعيه.

## لماذا يهمّ هذا في الخليج ومنطقة MENA

- **البيانات تبقى في الداخل.** fak يعمل self-host أولًا: ملفٌّ ثنائي ساكن يجلس أمام
  نموذج **محلي** أو مزوّد داخلي، مع residency فاشلٍ آمن على كل backend وسجلّ تدقيق لكل
  tool call. البيانات لا تغادر جهازك — ما يسند الامتثال لنظام حماية البيانات الشخصية
  (**PDPL**) في السعودية والإمارات، إذ لا تعبر البيانات الحدود.
- **الفاتورة بالدولار، والهامش بالريال والدرهم.** كل token يُعاد استخدامه هو ريالٌ سعودي (SAR)
  أو درهمٌ إماراتي (AED) لا يُدفَع؛ إعادة استخدام العمل المشترك في الجلسات الطويلة رافعةٌ
  مباشرة على الهامش.
- **لا عبور لأي قناة دفع.** fak بموجب **Apache-2.0**، مجاني، self-host — لا بطاقة، ولا
  فاتورة عابرة للحدود، ولا كيان قانوني. `git clone` ثمّ
  `go install github.com/anthony-chaudhary/fak/cmd/fak@latest` هو المسار كلّه.
