# fak — نواة الوكيل المدمَجة (مدخل بالعربية)

> هذه **صفحة دخول مُوطَّنة (entry point)**، وليست ترجمة كاملة للوثائق.
> الوثائق الكاملة بالإنجليزية — تعطيك هذه الصفحة جوهر fak، وبرهان الستين ثانية،
> ومسار التثبيت، ثم تحيلك إلى [الوثائق الإنجليزية](https://github.com/anthony-chaudhary/fak/blob/main/README.md).
> **ملاحظة:** هذه الترجمة مُولَّدة آليًّا وتنتظر مراجعة متحدث أصلي — لأي تصحيح
> افتح issue أو PR.
>
> **لغات أخرى:** انظر [مركز اللغات (i18n hub)](../README.md).

## fak في سطر واحد

**fak هو ثنائي Go واحد** يجلس بين وكيل الذكاء الاصطناعي والأدوات التي يستدعيها — يراجع كل
tool call *قبل أن يُنفَّذ*، ويعيد استخدام العمل المتكرر المشترك عبر الجلسة الطويلة. النتيجة:
نفس حلقة الوكيل تصبح **أكثر أمانًا وأقل كلفة وأسرع**، دون إعادة كتابة أي شيء.

أنت لا تعيد كتابة وكيلك — فقط توجّه base URL واحدًا إلى `fak serve`، فتمر كل استدعاءات
الأدوات أولًا عبر أرضية الصلاحيات (capability floor). أو غلِّف وكيلك القائم بأمر واحد:

```bash
fak manage claude      # يغلّف وكيلك الحالي بأمر واحد
```

## لماذا يهمّ هذا فرق الخليج ومنطقة الشرق الأوسط وشمال أفريقيا

- **الفاتورة بالدولار، والهامش بالريال والدرهم.** يُحتسب استهلاك التوكن بالدولار بينما
  إيراداتك وهامشك بالريال السعودي (SAR) والدرهم الإماراتي (AED). يعيد fak استخدام العمل
  المشترك في الجلسات الطويلة (مثل KV cache لـ system prompt وقائمة الأدوات)، فينجز **عملًا
  أقل بنحو 4.1× مقارنةً بمكدّس warm-cache مضبوط** على جلسة قياس من 50 دورة × 5 وكلاء.
  الرقم ~60× (نحو 19 ساعة تتقلّص إلى نحو 19 دقيقة) صحيح **فقط مقابل النمط الساذج** الذي
  يعيد إرسال كل شيء في كل مرة — لا تقدّمه كالعنوان الرئيسي؛ العنوان الأمين هو 4.1×. هذا مكسب
  للاستضافة الذاتية فقط، وينطبق على الأساطيل كثيفة القراءة.
- **بقاء البيانات داخل الحدود (PDPL في السعودية والإمارات).** fak يبدأ بالاستضافة الذاتية:
  ثنائي واحد ثابت (static) يجلس أمام **نموذج محلي** أو مزوّد داخلي، مع سلوك fail-closed للإقامة
  عبر كل backend، وأرضية صلاحيات default-deny تُفحَص داخل النواة على نفس مسار الاستدعاء.
  البيانات لا تغادر جهازك.
- **لا مدفوعات عابرة للحدود.** fak برخصة **Apache-2.0**، مجاني، ذاتي الاستضافة — لا بطاقة
  ائتمان، ولا فاتورة عابرة للحدود، ولا كيان قانوني. الطريق كله هو `git clone` ثم `go install`.
- **ثنائي واحد ثابت، بلا اعتماديات خارجية.** تشغيل بسيط للفرق الصغيرة — لا sidecar ولا مُخوِّل
  منفصل. نفس الأداة من الحاسوب المحمول إلى الأسطول؛ تضيف flags فقط لا مكوّنات.

## ما المشكلات التي يحلّها fak

- **الجلسات الطويلة تبقى رخيصة.** خصم prompt-cache من المزوّد لا يصمد إلا إذا بقيت البادئة
  المخزّنة (cached prefix) متطابقة بايتًا ببايت؛ يحذف fak الأدوار القديمة من الوسط مع إبقاء
  البادئة **متطابقة بايتيًّا**. يضمن fak تطابق البادئة بايتيًّا؛ أمّا إعادة استخدام المزوّد
  للـ cache فهي قرار المزوّد — ينقله fak ولا يدّعيه.
- **أمان default-deny.** تُفحص سياسة الصلاحيات *داخل* النواة على نفس مسار الاستدعاء، وهي
  **fail-closed**: أي فعل ليس على قائمة السماح لا يمكن أن يُنفَّذ مهما جرى إقناع النموذج به.
- **عزل حقن الأوامر (prompt injection).** تُحتجَز *نتائج* الأدوات المشبوهة خارج سياق النموذج
  بالكامل — بالبنية لا بمُصنِّف. المُكتشِف الذي يشير إليها يُعامَل تصميميًّا كأنه قابل للتحايل
  بنسبة ~100% — إضافة مكافِئة، لا الأرضية. في اختبارات حيّة: بلغ حقن الأوامر خط الأساس غير
  المحمي 5/5، وصدّه fak 5/5.

## برهان الستين ثانية (بلا مفتاح، بلا نموذج، بلا GPU)

```bash
go build -o fak ./cmd/fak
./fak preflight --policy examples/customer-support-readonly-policy.json --tool refund_payment --args "{}"   # -> DENY (POLICY_BLOCK)
./fak preflight --policy examples/customer-support-readonly-policy.json --tool search_kb     --args "{}"   # -> ALLOW
./fak agent --offline                                                                                       # injection blocked, task still completes
```

## مع نموذجك

fak لا يستبدل نموذجك — بل يحكمه (govern) ويخزّنه (cache). **Qwen2/Qwen3 و GLM-MoE** مُثبتة
كـ bit-exact في محرّك المرجع داخل النواة؛ وكل ما عداها (DeepSeek، Mistral، وأي نموذج مفتوح
الأوزان) يتصدّر عبر الواجهة المتوافقة مع OpenAI — عبر Ollama / vLLM / SGLang / llama.cpp /
LM Studio أو أي OpenAI-compatible API.
